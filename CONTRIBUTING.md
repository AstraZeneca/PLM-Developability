# Contributing

This repository is associated with a paper submission and is **not accepting contributions** at this time. The codebase is frozen at the version submitted for review.

## Using this code to extend benchmarks

You are welcome to fork this repository and use it as a base to benchmark additional protein language models or developability datasets. If you publish results based on this code, please cite the original paper (see [README.md](README.md)).

## Reporting issues

If you find a bug or have a question about reproducing the results, please open a GitHub issue. The maintainer will respond when possible, but note that the codebase will not be modified until the review process concludes.

## Questions

For questions about the science or methodology, contact the maintainer listed in [AUTHORS.md](AUTHORS.md).
